# trash/

Pasta para arquivos descontinuados do projeto, mantidos aqui por pedido do
professor para fins de histórico e auditoria — em vez de simplesmente
deletá-los e depender só do histórico do Git.

Não é uma convenção formal do Git/GitHub; é um padrão informal comum em
projetos acadêmicos. Qualquer arquivo movido para cá deixou de ser usado
pelo restante do projeto (notebooks, scripts em `estrutura/código/` e
documentos em `Consolidado/`), mas continua disponível para consulta.
